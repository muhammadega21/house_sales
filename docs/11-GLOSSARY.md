# GLOSSARY

| Istilah           | Definisi                                                             |
| ----------------- | -------------------------------------------------------------------- |
| KPR               | Kredit Pemilikan Rumah - fasilitas kredit bank untuk pembelian rumah |
| DP (Down Payment) | Uang muka - pembayaran awal pembelian rumah                          |
| Booking Fee       | Biaya pemesanan unit sebagai tanda penguncian                        |
| Akad Kredit       | Perjanjian resmi antara konsumen dan bank untuk KPR                  |
| Serah Terima      | Penyerahan kunci dan unit rumah kepada konsumen                      |
| BAST              | Berita Acara Serah Terima - dokumen resmi serah terima               |
| Indent            | Unit belum dibangun, dibangun setelah ada pemesanan                  |
| Ready Stock       | Unit sudah selesai dibangun, siap dihuni                             |
| Rumah Subsidi     | Rumah dengan bantuan pemerintah (FLPP/BP2BT)                         |
| Rumah Non-Subsidi | Rumah komersial tanpa bantuan pemerintah                             |
| FLPP              | Fasilitas Likuiditas Pembiayaan Perumahan                            |
| BP2BT             | Bantuan Pembiayaan Perumahan Berbasis Tabungan                       |
| Tenor             | Jangka waktu cicilan (dalam tahun)                                   |
| Plafon KPR        | Jumlah maksimum pinjaman dari bank                                   |
| Bunga Fixed       | Suku bunga tetap selama periode tertentu                             |
| Bunga Floating    | Suku bunga mengambang mengikuti pasar                                |
| Bunga Flat        | Bunga dihitung dari pokok awal selama tenor                          |
| Anuitas           | Metode cicilan dengan porsi bunga menurun, pokok meningkat           |
| Cash Bertahap     | Pembayaran dicicil langsung ke developer tanpa bank                  |
| Cash Keras        | Pembayaran sekaligus/lunas dalam waktu singkat                       |
| Prospek           | Calon konsumen yang belum melakukan transaksi                        |
| Closing           | Transaksi berhasil (akad/serah terima)                               |
| Conversion Rate   | Persentase prospek yang menjadi closing                              |
| CRM               | Customer Relationship Management                                     |
| RBAC              | Role-Based Access Control                                            |
| NIK               | Nomor Induk Kependudukan (nomor KTP)                                 |
| KK                | Kartu Keluarga                                                       |
| NPWP              | Nomor Pokok Wajib Pajak                                              |
| SKU               | Surat Keterangan Usaha                                               |
| SIUP              | Surat Izin Usaha Perdagangan                                         |
| Marketing         | Tenaga pemasaran/penjualan perusahaan                                |
| Komisi            | Imbalan untuk marketing atas closing penjualan                       |
| Target            | Jumlah unit yang harus dijual marketing per periode                  |
| Perumahan         | Kawasan/cluster yang berisi beberapa unit rumah                      |
| Unit Rumah        | Satu rumah individual dalam kawasan perumahan                        |
| Tipe Rumah        | Klasifikasi ukuran (36/60, 45/72, dll)                               |
| Status Unit       | Kondisi ketersediaan unit (tersedia/dibooking/dijual/dibatalkan)      |
| Status Penjualan  | Tahapan transaksi (prospek → booking → pengajuan_kpr → akad → serah_terima) |
